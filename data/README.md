# Machine-readable claims

`claims.json` is an **index of atomic assertions**, not an endorsement or substitute for reading linked sources. It is intentionally conservative: no claim is labeled `documented` without a usable public source. Keep null URLs null; do not fabricate links.

Field overview: `id` stable, `statement` atomic, `status` epistemic type, `scope` conditions, `last_reviewed` date, `source_type`, `evidence` provenance, `limits`, `article` explanatory Markdown, `decision_relevance`, `verification_needed`.

Schema/checker version is 0.1.0; fields may expand. Breaking changes should increment schema version.
