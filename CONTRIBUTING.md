# Contributing to Herc & Heimy Research

We welcome falsifiable evidence, corrections, and counterexamples. We are not collecting unverified tips as facts.

## Report a finding

Use this template in a GitHub issue or pull request:

- **Claim ID or new topic:**
- **What was observed or tested?**
- **When and under which game version / event?**
- **Account/troop/captain configuration (only as necessary; redact identity):**
- **Control group and changed variable:**
- **Raw results and units:**
- **Screenshot or public evidence URL (authorized to share):**
- **Alternative explanations / suspected confounders:**
- **Proposed status:** observed_player / documented / derived / working_assumption / hypothesis / open_question

If a claim is contested, keep the dissenting result, explain the conditions, and leave the rule unresolved until evidence discriminates between explanations.

## Format

- Human-readable explanation in Markdown under a topic folder.
- Atomic record in `data/claims.json` with a stable `TB-*` ID.
- Cross-link article and JSON record; update `last_reviewed` only after meaningful review.
- Avoid mixing optimization advice for one account with universal game rules.

Do not include private chat transcripts or privately shared images without permission. Don't submit macros, game-client impersonation code, credentials, or bypass instructions.
